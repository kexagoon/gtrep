📘 Инструкция по использованию

1Добавление команд

Нажимайте на клавиши в нижней панели, чтобы добавить их в скрипт. Каждая команда появится в верхней области.

2Переключение вкладок

Используйте вкладки внизу для доступа к разным типам команд:

  • Клавиши - буквы, цифры, символы
  • Модификаторы - Ctrl, Alt, Shift и комбинации
  • Функции - Enter, Esc, F-клавиши
  • Быстрые - готовые наборы команд
  • Система - задержки, текст, комментарии
  • Задержки - готовые таймеры 0.1сек - 1мин и спецклавиши

3Очистка скрипта

Для очистки всего скрипта нажмите кнопку "🗑 Очистить" вверху справа от списка команд.

Подтвердите действие в появившемся окне.

4Изменение порядка

Зажмите и перетащите команды вверх или вниз, чтобы изменить их порядок выполнения.

5Редактирование

Нажмите на ✏ рядом с командой, чтобы отредактировать её параметры (текст, задержку).

6Экспорт скрипта

Нажмите "📤 Экспорт" и выберите формат:

  • DuckyScript - для Hak5 USB Rubber Ducky
  • Flipper Zero - для Flipper Zero BadUSB
  • ESP32 Arduino - для ESP32 BLE Keyboard

Скопируйте готовый скрипт одним нажатием на кнопку.

⚠️ Важно!

Если кнопка "Очистить" не работает:

  • Убедитесь, что в скрипте есть команды для очистки
  • Проверьте, не блокирует ли браузер всплывающие окна
  • Попробуйте обновить страницу и добавить команды заново
