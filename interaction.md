# Bad Bluetooth Script Builder - Архитектура и взаимодействие

## Общая архитектура

Приложение представляет собой одностраничное веб-приложение (SPA) с мобильной ориентацией, построенное на чистом JavaScript без внешних фреймворков для максимальной производительности и минимального размера.

## Структура компонентов

### 1. Главный экран приложения

**Верхняя панель**
- Логотип/название приложения
- Кнопка "Экспорт скрипта" (открывает модальное окно с кодом)
- Индикатор количества команд

**Основная область редактора**
- Поле визуализации скрипта (список добавленных команд)
- Каждая команда отображается как карточка с:
  - Иконкой типа команды
  - Описанием действия
  - Кнопками редактирования/удаления
  - Перетаскиванием для изменения порядка

**Нижняя панель команд**
- Табы категорий команд:
  - "Клавиши" (буквы, цифры, спецсимволы)
  - "Модификаторы" (Ctrl, Alt, Shift, Win)
  - "Функции" (F1-F12, Enter, Esc, Space)
  - "Быстрые команды" (предустановленные комбинации)
  - "Система" (SLEEP, DELAY, PAUSE)

### 2. Система команд

**Базовые команды клавиш**
- Одиночные клавиши: A-Z, 0-9, спецсимволы
- Модификаторы: CTRL, ALT, SHIFT, GUI (Win/Cmd)
- Функциональные клавиши: ENTER, ESC, SPACE, TAB, BACKSPACE
- Клавиши навигации: ARROW_UP, ARROW_DOWN, ARROW_LEFT, ARROW_RIGHT

**Комбинированные команды**
- Горячие клавиши: CTRL+C, CTRL+V, CTRL+Z, CTRL+Y
- Системные команды: WIN+R, WIN+D, ALT+TAB, ALT+F4
- Кастомные комбинации: любые сочетания модификаторов + клавиш

**Специальные команды**
- SLEEP (задержка в миллисекундах)
- PRINT (вывод текста)
- STRING (ввод текста с задержкой)
- REM (комментарии)

**Быстрые шаблоны**
- "Открыть CMD": WIN+R + "cmd" + ENTER
- "Открыть PowerShell": WIN+R + "powershell" + ENTER
- "Запустить браузер": WIN+R + "chrome" + ENTER
- "Создать пользователя": Командная строка создания пользователя
- "Скачать файл": PowerShell команда загрузки

### 3. Функциональность редактора

**Добавление команд**
- Нажатие на кнопку команды добавляет её в конец скрипта
- Для комбинированных команд открывается окно выбора модификаторов
- Для текстовых команд открывается поле ввода текста
- Для SLEEP открывается поле ввода времени задержки

**Редактирование команд**
- Нажатие на карточку команды открывает окно редактирования
- Изменение параметров команды
- Предпросмотр результата

**Управление порядком**
- Перетаскивание карточек команд (drag & drop)
- Кнопки "Вверх" и "Вниз" для перемещения
- Кнопка "Удалить" с подтверждением

**Генерация скрипта**
- Автоматическое преобразование в выбранный формат
- Поддержка форматов: DuckyScript, Flipper Zero, ESP32
- Копирование в буфер обмена одним нажатием
- Предпросмотр перед копированием

### 4. Интерактивные элементы

**Модальные окна**
- Окно экспорта скрипта с выбором формата
- Окно редактирования команды
- Окно настроек приложения
- Окно справки по командам

**Анимации**
- Плавное появление карточек команд
- Подсветка при нажатии кнопок
- Эффекты перетаскивания
- Мерцание курсора в полях ввода

**Обратная связь**
- Визуальное подтверждение добавления команды
- Уведомления о копировании скрипта
- Индикаторы загрузки
- Сообщения об ошибках

### 5. Навигация и поток работы

**Основной сценарий использования**
1. Пользователь открывает приложение
2. Выбирает категорию команд (Клавиши/Модификаторы/Функции)
3. Нажимает на нужные команды для добавления в скрипт
4. При необходимости редактирует параметры команд
5. Меняет порядок команд перетаскиванием
6. Нажимает "Экспорт" для генерации скрипта
7. Выбирает формат и копирует результат

**Дополнительные функции**
- Очистка всего скрипта
- Загрузка предустановленных шаблонов
- Сохранение скриптов в локальном хранилище
- Поделиться скриптом (генерация ссылки)

## Техническая реализация

### Структура данных

```javascript
// Объект команды
{
  id: 'unique_id',
  type: 'key' | 'combo' | 'text' | 'sleep' | 'rem',
  name: 'ENTER',
  description: 'Нажатие клавиши Enter',
  parameters: {
    modifiers: [], // для комбинаций
    text: '', // для текстовых команд
    delay: 0 // для задержек
  },
  icon: 'icon_name'
}

// Скрипт
{
  commands: [/* массив команд */],
  metadata: {
    name: 'Мой скрипт',
    created: timestamp,
    modified: timestamp
  }
}
```

### Генераторы скриптов

**DuckyScript формат**
```
REM Сгенерированный скрипт
STRING Привет мир
ENTER
DELAY 1000
GUI r
STRING cmd
ENTER
```

**Flipper Zero формат**
```
Print("Привет мир")
Press("ENTER")
Delay(1000)
Hold("GUI") + Print("r")
Release("GUI")
Print("cmd")
Press("ENTER")
```

**ESP32 Arduino формат**
```
bleKeyboard.print("Привет мир");
bleKeyboard.write(KEY_RETURN);
delay(1000);
bleKeyboard.press(KEY_LEFT_GUI);
bleKeyboard.print("r");
bleKeyboard.releaseAll();
delay(500);
bleKeyboard.print("cmd");
bleKeyboard.write(KEY_RETURN);
```

Эта архитектура обеспечивает максимальную гибкость и удобство использования для создания сложных скриптов автоматизации на мобильном устройстве.
