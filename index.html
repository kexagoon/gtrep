Шпаргалка команд

STRING: Печатает текст. Вводи адрес сайта или команды терминала.
DELAY: Пауза. Писать в миллисекундах (1000 = 1 секунда). Нужно, чтобы система успела "прогрузиться".
GUI: Клавиша Windows или Command (Mac). Обычно GUI + R открывает "Выполнить".
ENTER: Нажатие "Ввод". Используй после STRING для запуска команд.
CTRL/ALT/SHIFT: Модификаторы для горячих клавиш.
